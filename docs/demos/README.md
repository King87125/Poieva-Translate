# Usage demos

These GIFs use actual captures of Poieva Translate build 56 and a local AppKit test editor with public sample text. No real messages, API keys or private windows are shown. Translation uses the built-in Apple service.

- `input-replacement.gif`: the original Chinese draft, followed by the English text actually written back into the same editor.
- `selection-preview.gif`: the English source before selection, the selected sentence, and its actual Chinese preview. The captured preview window is arranged over the source capture so both remain readable.

These are edited sequences of captured states, not continuous screen recordings or speed measurements. Pauses are extended for readability. The recording setup used the user's custom Command+D / Command+F shortcuts; the READMEs list the application's default shortcuts and explain how to customize them.

The source captures and temporary test editor stay in the ignored `.build/readme-demos/` directory. The published GIFs contain no mocked translation output or redrawn application controls. Both language versions of the README reuse these same demonstrations.
